# WaCow Project Rules

## Permission Rules
- ALWAYS ask for my permission before modifying any file
- ALWAYS ask for my permission before creating any new file
- ALWAYS ask for my permission before deleting anything
- ALWAYS ask for my permission before running any terminal commands
- NEVER make changes without explicit approval

## How to Work With Me
- Explain what you plan to do BEFORE doing it
- Show me the exact changes you want to make first
- Wait for me to say "yes", "go ahead", or "approved" before proceeding
- If unsure, ask — don't assume

## Project Info
- This is a React Native + Expo app called WaCow
- Backend is Supabase
- Theme file is at src/style/theme.js
- Never hardcode colors — always use the theme file
